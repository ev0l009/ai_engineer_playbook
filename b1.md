# 🧠 03 — THE BIG IDEA

## What is programming?

Programming is the process of creating instructions that tell a computer how to perform tasks.

Think about a computer as a machine that can perform many operations incredibly quickly.

However, a computer does not automatically know what you want it to do.

You have to provide instructions.

For example, imagine you want a computer to calculate the total cost of three football jerseys.

You need to tell it:

1. What the price of one jersey is.
2. How many jerseys you want.
3. How to calculate the total.
4. What result to display.

Those instructions form a program.

### A simple definition

**Programming is the process of writing and organising instructions that a computer can execute to solve problems or perform tasks.**

Let's break that definition down.

| Term | Meaning |
|---|---|
| Programming | Creating instructions for a computer |
| Program | A set of instructions designed to perform a task |
| Computer | The machine that executes instructions |
| Programmer | The person who designs and writes those instructions |
| Problem | Something that needs to be solved |
| Solution | The method or result that addresses the problem |

### 🧠 Remember this:

A programmer doesn't simply write code.

A programmer identifies a problem, thinks about how to solve it, and then translates that solution into instructions a computer can understand.

**The thinking comes before the coding.**

# ⚙️ 05 — HOW DOES A COMPUTER FOLLOW INSTRUCTIONS?

A computer follows instructions provided through programs.

However, it is important to understand something:

**Computers do not understand your intentions. They execute instructions according to how those instructions are written and interpreted.**

Consider this instruction:

> Calculate the total cost of five football jerseys if each jersey costs ₦8,000.

A human can understand what needs to happen.

But a computer needs instructions expressed in a form it can process.

We can break the task into smaller steps:

1. Store the price of one jersey.
2. Store the number of jerseys.
3. Multiply the price by the quantity.
4. Display the result.

Let's represent that mathematically:

Price = ₦8,000  
Quantity = 5

Total = 8,000 × 5

Total = ₦40,000

The computer can perform this calculation when given an appropriate program.

### The important lesson

Computers are extremely capable, but they need clear instructions.

If your instructions are incomplete, confusing, or incorrect, your program may not produce the result you intended.

This is why logical thinking is essential to programming.

# 🧩 06 — THE THREE FUNDAMENTAL STAGES OF A PROGRAM

One of the most important ideas in programming is:

**Input → Processing → Output**

Almost every beginner program can be understood using these three stages.

Let's explore them.

## 1. INPUT

Input is the information supplied to a program.

For example, imagine a program that calculates the total cost of football boots.

The information supplied might be:

- Price: ₦25,000
- Quantity: 2

These are inputs.

## 2. PROCESSING

Processing is what the program does with the information.

In our example, the program multiplies the price by the quantity.

₦25,000 × 2 = ₦50,000

That calculation is the processing stage.

## 3. OUTPUT

Output is the result produced by the program.

In this example:

`Total cost: ₦50,000`

That is the output.

### Visual representation

```text
             INPUT
               |
               |
       Price = ₦25,000
       Quantity = 2
               |
               v
          PROCESSING
               |
               |
        25,000 × 2
               |
               v
            OUTPUT
               |
               |
       Total = ₦50,000
```

### Another example: Student results

Imagine a program that calculates a student's total score.

**Input:**
- Mathematics = 70
- English = 65
- Biology = 80

**Processing:**

70 + 65 + 80 = 215

**Output:**

Total score = 215

### Mental model

Whenever you encounter a programming problem, ask yourself:

1. What information does the program need?
2. What should the program do with that information?
3. What result should the program produce?

These three questions will help you understand many programming problems before writing any code.

# 🧠 07 — WHAT IS AN ALGORITHM?

Now we are getting into an important programming concept.

An **algorithm** is a sequence of logical steps designed to solve a problem or complete a task.

In simpler language:

An algorithm is a plan for solving a problem.

It describes what needs to happen and in what order.

### Example: Making a cup of tea

Imagine you want to make a cup of tea.

You could describe the process using these steps:

1. Get a cup.
2. Put a tea bag inside the cup.
3. Heat some water.
4. Pour the hot water into the cup.
5. Allow the tea to brew.
6. Remove the tea bag.
7. Add sugar if desired.
8. Stir the tea.
9. Serve.

This is an algorithm.

It gives you a sequence of instructions for completing a task.

### Why does the order matter?

Consider what would happen if you rearranged those steps.

For example:

1. Remove the tea bag.
2. Pour water into the cup.
3. Get a cup.
4. Heat the water.

The instructions are poorly organised.

The task may fail because the steps are not arranged in a sensible order.

**Programming requires logical sequencing.**

The computer follows the instructions you provide, so the order of those instructions matters.

# 🧱 08 — ALGORITHMS AND PROGRAMS: WHAT IS THE DIFFERENCE?

These two concepts are related, but they are not the same.

| Algorithm | Program |
|---|---|
| A logical plan for solving a problem | Instructions written in a programming language |
| Focuses on the steps | Focuses on executable implementation |
| Can be written in plain English | Written using programming language syntax |
| Describes how to solve something | Tells the computer how to perform the task |

### Example problem

Calculate the area of a rectangle.

**Algorithm:**

1. Obtain the rectangle's length.
2. Obtain its width.
3. Multiply the length by the width.
4. Display the area.

**Mathematical formula:**

Area = Length × Width

**Python implementation:**

```python
length = 10
width = 5

area = length * width

print(area)
```

**Expected output:**

```text
50
```

Notice what happened.

We first created a logical plan.

Then we translated that plan into Python instructions.

This is a fundamental programming workflow:

```text
PROBLEM
   |
   v
UNDERSTAND THE PROBLEM
   |
   v
DESIGN AN ALGORITHM
   |
   v
WRITE THE CODE
   |
   v
RUN THE PROGRAM
   |
   v
CHECK THE RESULT
```

# ✍️ 09 — HOW DO PROGRAMMERS REPRESENT ALGORITHMS?

There are different ways to describe an algorithm.

For now, we will focus on two beginner-friendly methods:

1. Pseudocode.
2. Flowcharts.

## A. PSEUDOCODE

Pseudocode is a way of describing program instructions using simple, human-readable language.

It resembles programming logic but does not follow the strict syntax of a particular programming language.

For example, imagine a program that calculates someone's age.

### Pseudocode

```text
START

SET birth_year
SET current_year

CALCULATE age = current_year - birth_year

DISPLAY age

END
```

This is not Python code.

It is a description of the instructions the program needs to perform.

### Why is pseudocode useful?

It helps you:

- Organise your thoughts.
- Understand the problem.
- Identify missing steps.
- Plan your solution before coding.
- Communicate your logic without worrying about programming syntax.

### Another example: Checking whether a player is eligible

Imagine a football academy only accepts players aged 18 or older.

Pseudocode:

```text
START

GET player age

IF player age is 18 or older
    DISPLAY "Eligible"
OTHERWISE
    DISPLAY "Not eligible"

END
```

Don't worry about the `IF` structure yet.

We will study conditionals in Batch 8.

For now, focus on understanding the logic.

## B. FLOWCHARTS

A flowchart is a visual representation of an algorithm.

It uses shapes and arrows to show the sequence of actions.

Here are some common flowchart symbols:

| Symbol | Meaning |
|---|---|
| Oval | Start or End |
| Rectangle | Process or instruction |
| Parallelogram | Input or Output |
| Diamond | Decision |
| Arrow | Direction of flow |

### Example: Adding two numbers

```text
       _____________
      /             \
     /     START     \
     \               /
      \_____________/
             |
             v
      /--------------/
     /  Enter number /
    /      A        /
    \--------------\
             |
             v
      /--------------/
     /  Enter number /
    /      B        /
    \--------------\
             |
             v
      +----------------+
      |  A + B = SUM   |
      +----------------+
             |
             v
      /--------------/
     / Display SUM  /
    /                /
    \--------------/
             |
             v
       _____________
      /             \
     /      END      \
     \               /
      \_____________/
```

### Important distinction

- Pseudocode describes the steps in readable language.
- A flowchart shows those steps visually.
- A program implements the solution using a programming language.

You don't need to become an expert at drawing flowcharts in this batch.

You need to understand what they represent and why they are useful.

# 🐍 10 — WHAT IS A PROGRAMMING LANGUAGE?

We know that computers execute instructions.

But how do programmers write those instructions?

They use programming languages.

A programming language provides rules and structures that allow humans to express instructions for computers.

Examples include:

| Language | Common Uses |
|---|---|
| Python | Automation, data analysis, artificial intelligence, web development |
| JavaScript | Web development and interactive websites |
| Java | Enterprise software and Android development |
| C | Systems programming and embedded systems |
| C++ | Game development and performance-intensive software |
| C# | Application and game development |

There are many programming languages, and each has its own characteristics.

### Why are we learning Python?

We will use Python throughout this foundation stage.

Python is popular because:

- Its syntax is relatively readable.
- It is useful for many different types of projects.
- It has a large ecosystem of libraries.
- It is widely used in professional software development.
- It is suitable for learning fundamental programming concepts.

### What is syntax?

Syntax refers to the rules governing how instructions must be written in a programming language.

Think of it like grammar in a human language.

For example, in English:

> The player scored a goal.

This is a meaningful sentence.

But:

> Goal a scored player the.

The words are recognisable, but the arrangement is incorrect.

Programming languages also have rules.

In Python:

```python
print("Hello, world!")
```

This is valid Python syntax.

But:

```python
print("Hello, world!"
```

This is missing a closing parenthesis.

The second example produces a syntax error.

We will explore Python syntax more thoroughly in Batch 2.

# 🧠 12 — THINK LIKE A PROGRAMMER

This is where your actual problem-solving development begins.

A common beginner mistake is to see a problem and immediately start writing code.

Don't do that.

Train yourself to understand the problem first.

Let's introduce a simple problem-solving method.

## The 5-Step Programming Approach

### Step 1: Understand the problem

What exactly are you trying to achieve?

### Step 2: Identify the requirements

What information do you need?

What result should be produced?

### Step 3: Break the problem into smaller steps

What actions must happen, and in what order?

### Step 4: Implement the solution

Translate your planned steps into code.

### Step 5: Test the result

Run the program and check whether it produces the expected output.

### Let's apply it.

**Problem:**

A football academy wants to calculate the total number of players across three age groups.

The age groups contain:

- Under-12: 15 players.
- Under-15: 20 players.
- Under-18: 18 players.

Calculate the total number of players.

**Step 1 — Understand the problem**

We need to calculate the combined player count.

**Step 2 — Identify the requirements**

We need three numbers:

- 15
- 20
- 18

**Step 3 — Plan the solution**

Add the three numbers together.

**Step 4 — Implement the solution**

```python
print(15 + 20 + 18)
```

**Step 5 — Test the result**

Expected output:

```text
53
```

The solution works.

### Your programming mindset

Whenever you face a problem, don't ask only:

"What code should I write?"

Also ask:

"What is the actual problem, and what steps would solve it?"

That second question is the foundation of independent problem-solving.

# 🚨 13 — COMMON BEGINNER MISCONCEPTIONS

Let's eliminate some misunderstandings before they become habits.

### Misconception 1: Programming is just memorising code.

**Reality:** Programming requires reasoning, planning, problem-solving, and understanding how instructions work together.

You will learn syntax over time, but memorising syntax alone will not make you a capable programmer.

### Misconception 2: Computers know what you mean.

**Reality:** Computers execute instructions. They do not automatically understand your intentions.

If your instructions are incorrect, the result may also be incorrect.

### Misconception 3: Every problem has only one solution.

**Reality:** Many programming problems can be solved using different approaches.

Some solutions may be simpler, faster, or easier to maintain than others.

### Misconception 4: Errors mean you're bad at programming.

**Reality:** Errors are part of programming.

Programmers make mistakes, investigate them, correct them, and learn from the process.

### Misconception 5: You should start coding immediately.

**Reality:** Understanding the problem and planning the solution often saves time and prevents unnecessary mistakes.
