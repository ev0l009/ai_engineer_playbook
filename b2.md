# ⚙️ 04 — HOW PYTHON WORKS

When you write Python code, you need a way to execute it.

This is where the Python interpreter comes in.

## What is an interpreter?

An interpreter is software that processes and executes instructions written in a programming language.

For our purposes, think of the Python interpreter as the software responsible for running your Python code.

Consider:

```python
print("I am learning Python")
```

When Python executes this instruction, it displays:

```text
I am learning Python
```

The interpreter handles the process of executing the instruction.

### A simplified execution model

```text
       YOUR PYTHON CODE
              |
              v
      PYTHON INTERPRETER
              |
              v
       EXECUTION PROCESS
              |
              v
         PROGRAM OUTPUT
```

### Important distinction

You write the code.

The interpreter executes it.

The output is what you see as a result of execution.

These are three different parts of the programming process.

# 💻 05 — GETTING READY TO USE PYTHON

Before writing larger programs, you need somewhere to write and execute Python code.

There are several ways to do this.

## Option 1: Python's Interactive Shell

The interactive shell allows you to enter Python instructions and see their results immediately.

For example:

```python
>>> print("Hello")
Hello
```

You enter an instruction.

Python executes it.

You immediately see the result.

You can also perform calculations:

```python
>>> 10 + 5
15
```

The shell is useful for:

- Testing short instructions.
- Performing quick calculations.
- Experimenting with Python.
- Learning how individual expressions behave.

### What does `>>>` mean?

The `>>>` symbol is the standard prompt shown by Python's interactive interpreter.

It indicates that Python is ready for an instruction.

**Important:** You normally type the instruction after the prompt. You do not include `>>>` when writing code in a Python script file.

## Option 2: Python Script Files

A Python script is a file containing Python instructions.

Python script files usually have the `.py` extension.

For example:

```text
academy.py
```

You could put this code inside:

```python
print("Welcome to Rising Stars Academy")
print("Python programming has begun")
```

When you run the script, Python executes the instructions.

Expected output:

```text
Welcome to Rising Stars Academy
Python programming has begun
```

### Interactive shell vs script file

| Interactive Shell | Python Script |
|---|---|
| Executes instructions as you enter them | Stores instructions in a file |
| Useful for quick experiments | Useful for complete programs |
| Results appear immediately | Results appear when the script runs |
| Usually used for short tests | Suitable for larger programs |

### Which should you use?

Both are useful.

Use the interactive shell to experiment.

Use script files to build and save programs.

# 🔢 07 — SEQUENTIAL EXECUTION

Sequential execution means that instructions are carried out in their written order, unless a language feature changes the normal flow.

Consider:

```python
print("First")
print("Second")
print("Third")
```

Output:

```text
First
Second
Third
```

Now change the order:

```python
print("Third")
print("First")
print("Second")
```

Output:

```text
Third
First
Second
```

The output changes because the instructions are written in a different order.

### Mental model: A numbered instruction list

Imagine someone gives you these instructions:

1. Wake up.
2. Brush your teeth.
3. Take a shower.
4. Get dressed.

You naturally follow them in order.

Python normally executes instructions in a similar sequential manner.

### Trace this program

```python

```

What will the output be?

Before reading the answer, try to predict it.

**Expected output:**

```text

Academy closing
```

### Why does this matter?

When writing programs, you must think about the order in which instructions should happen.

Incorrect ordering can produce incorrect behaviour, even when every individual instruction is valid.

# 🧠 08 — UNDERSTANDING PYTHON SYNTAX

Syntax refers to the rules governing how Python instructions must be written.

Python is strict about its syntax.

A small mistake can prevent a program from running.

Let's examine some examples.

## Rule 1: Use parentheses correctly

Correct:

```python
print("Hello")
```

Incorrect:

```python
print("Hello"
```

The second instruction is missing a closing parenthesis.

## Rule 2: Use quotation marks correctly

Correct:

```python
print("Learning Python")
```

Incorrect:

```python
print("Learning Python)
```

The second example is missing a closing quotation mark.

## Rule 3: Pay attention to spelling

Correct:

```python
print("Welcome")
```

Incorrect:

```python
pritn("Welcome")
```

Python does not recognise `pritn` as the built-in `print()` function.

## Rule 4: Pay attention to capitalisation

Python is case-sensitive.

That means uppercase and lowercase letters are treated differently.

For example:

```python
print("Hello")
```

is valid.

But:

```python
Print("Hello")
```

does not refer to the same built-in function.

Similarly:

```python
PRINT("Hello")
```

is not equivalent to `print()`.

### Key lesson

Python expects instructions to follow its syntax rules.

When something is written incorrectly, Python may raise an error.

# 📝 09 — COMMENTS IN PYTHON

Comments are notes written inside your code for human readers.

They help explain what your code is doing.

Python ignores ordinary comments when executing a program.

A single-line comment begins with the `#` symbol.

### Example 1

```python
# This program welcomes the user

print("Welcome to Python")
```

Output:

```text
Welcome to Python
```

The comment is not displayed.

### Example 2

```python
# Display academy information

print("Rising Stars Academy")
print("Location: Ibadan")
print("Players: 45")
```

### Example 3 — Comments beside instructions

```python
print("Academy Report")  # Display report title
print("Players: 45")     # Display player count
```

### Why use comments?

Comments can help you:

- Explain complicated instructions.
- Describe what a section of code does.
- Make programs easier to understand.
- Leave reminders for future development.
- Help other programmers understand your work.

### When should you use comments?

Use comments when they add useful information.

Avoid commenting on every obvious instruction.

For example:

```python
# Print Hello
print("Hello")
```

This comment adds very little because the instruction already makes its purpose clear.

A more useful comment would explain the purpose of a larger section.

### Important note about comments

The `#` symbol begins a comment in ordinary Python code.

Anything after it on that line is treated as a comment.

For now, focus on single-line comments. Python also supports documentation strings, which we will encounter later when studying functions.

# 📐 10 — INDENTATION: A VERY IMPORTANT PYTHON FEATURE

Indentation refers to the spaces placed at the beginning of a line of code.

Python uses indentation to organise code and define blocks of instructions.

This is particularly important when working with conditionals, loops, functions, and other structures.

### Example: Correct indentation

```python
if True:
    print("Welcome")
```

Output:

```text
Welcome
```

The `print()` instruction is indented.

It belongs to the block controlled by the `if` statement.

We will study `if` statements properly in Batch 8.

For now, understand that indentation is part of Python's syntax.

### Example: Incorrect indentation

```python
if True:
print("Welcome")
```

This produces an indentation error because Python expects the block to be indented.

### How much indentation should you use?

The standard Python convention is four spaces per indentation level.

Example:

```python
if True:
    print("First instruction")
    print("Second instruction")
```

Both instructions are indented by four spaces.

### Another example

```python
if True:
    print("Inside the block")

print("Outside the block")
```

The first `print()` belongs to the indented block.

The second `print()` is outside that block.

### Mental model

Think of indentation as grouping.

Instructions with the same indentation level often belong to the same logical section of code.

### Common indentation mistakes

- Forgetting to indent instructions inside a block.
- Using inconsistent indentation.
- Adding unnecessary indentation.
- Mixing tabs and spaces carelessly.

**Beginner rule:** Use four spaces for each indentation level and remain consistent.

# 🧪 13 — UNDERSTANDING PYTHON ERRORS

Errors are a normal part of programming.

You will encounter them regularly, even when you become an experienced programmer.

The important thing is learning how to understand and correct them.

For this batch, we will focus on three common categories.

## 1. Syntax Errors

A syntax error occurs when Python encounters code that does not follow the language's syntax rules.

Example:

```python
print("Hello"
```

The closing parenthesis is missing.

Python cannot correctly interpret the instruction.

## 2. Indentation Errors

An indentation error occurs when code is not indented correctly.

Example:

```python
if True:
print("Hello")
```

Python expects the instruction inside the block to be indented.

## 3. Runtime Errors

A runtime error occurs while a program is executing.

For example:

```python
print(10 / 0)
```

This produces a division-by-zero error.

The instruction is written in valid Python syntax, but the operation cannot be completed.

### Understanding the difference

| Error | What happened? |
|---|---|
| Syntax Error | The code violates Python's syntax rules |
| Indentation Error | The indentation is incorrect |
| Runtime Error | A problem occurs during execution |

### What should you do when an error appears?

Follow this process:

1. Read the error message.
2. Identify the line where the problem occurred.
3. Examine the instruction.
4. Identify what is wrong.
5. Correct the code.
6. Run the program again.

### Debugging mindset

Don't immediately delete everything when an error appears.

Investigate the problem.

Errors often provide clues about what needs to be corrected.

# 🔎 14 — READING AND TRACING PYTHON CODE

A programmer should be able to read code and predict what it will do.

This is called code tracing.

Let's practise.

### Example 1

```python
print("A")
print("B")
print("C")
```

Trace:

| Step | Instruction | Output |
|---|---|---|
| 1 | `print("A")` | A |
| 2 | `print("B")` | B |
| 3 | `print("C")` | C |

Final output:

```text
A
B
C
```

### Example 2

```python
print(5 + 5)
print(10 * 2)
print(30 - 5)
```

Trace:

| Step | Calculation | Output |
|---|---|---|
| 1 | 5 + 5 | 10 |
| 2 | 10 × 2 | 20 |
| 3 | 30 - 5 | 25 |

Final output:

```text
10
20
25
```

### Example 3

```python
print("Start")
print(5 + 5)
print("Finish")
```

Final output:

```text
Start
10
Finish
```

### Example 4 — Identify the problem

```python
print("Welcome")
print(10 + 5)
print("Goodbye"
```

The first two instructions are valid.

The third instruction contains a syntax error.

In a normal Python script, this syntax error prevents the script from executing successfully.

### Why practise tracing?

Tracing helps you:

- Understand how instructions execute.
- Predict program output.
- Identify logical mistakes.
- Read other people's code.
- Develop independent problem-solving skills.
