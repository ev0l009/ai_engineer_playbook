# 🧠 03 — THE BIG IDEA: WHAT IS A VARIABLE?

A variable is a named reference used to store and access a value in a program.

Let's make that simpler.

Imagine you have a labelled box.

The label says:

`player_name`

Inside the box is:

`David`

Whenever you need the player's name, you can refer to the label instead of remembering where the information is stored.

In Python, we create a variable using an assignment statement.

```python
player_name = "David"
```

Let's break this down.

| Component | Meaning |
|---|---|
| `player_name` | Variable name |
| `=` | Assignment operator |
| `"David"` | Value being assigned |

The instruction tells Python to associate the name `player_name` with the value `"David"`.

Now you can use that variable elsewhere in your program.

```python
player_name = "David"

print(player_name)
```

**Expected output:**

```text
David
```

Notice something important.

In the first instruction, we assigned a value to the variable.

In the second instruction, we accessed the value using the variable's name.

### Mental model: A labelled storage location

```text
       VARIABLE
      player_name
           |
           v
     +-----------+
     |   David   |
     +-----------+
```

Think of a variable as a name through which your program can access stored information.

### Important distinction

A variable is not the same thing as the value it refers to.

For example:

```python
player_name = "David"
```

- `player_name` is the variable name.
- `"David"` is the value.

This distinction is fundamental to understanding Python.

# 🧠 05 — VARIABLE ASSIGNMENT

Let's examine the assignment operator more closely.

In Python, the single equals sign `=` is used to assign a value to a variable.

Example:

```python
score = 85
```

This means:

Assign the value `85` to the variable `score`.

It does not mean that `score` and `85` are mathematically equal in the way an equation is written.

It is an instruction.

### Another example

```python
academy_name = "Elite Football Academy"
```

This assigns a text value to the variable.

### Assignment happens from right to left

Consider:

```python
players = 50
```

Python evaluates the value on the right and assigns it to the name on the left.

Visual representation:

```text
       50
        |
        v
   players
```

### More examples

```python
goals = 3
matches = 5
coach_name = "John"
location = "Ibadan"
```

These instructions create four variable names and associate each with a value.

### Common beginner confusion

Consider:

```python
score = 80
```

This is assignment.

But:

```python
score == 80
```

This is a comparison expression.

The double equals sign `==` is not the same as the single equals sign `=`.

We will explore comparison operators in Batch 5.

For now, remember:

- `=` assigns a value.
- `==` compares two values.

# ✏️ 06 — VARIABLE NAMING RULES

You cannot give Python variables absolutely any name you want.

Python has naming rules that must be followed.

Let's examine them.

## Rule 1: Variable names can contain letters

Valid:

```python
name = "David"
player = "Michael"
academy = "Rising Stars"
```

## Rule 2: Variable names can contain numbers

However, they cannot begin with a number.

Valid:

```python
player1 = "David"
player2 = "Michael"
team2026 = "Rising Stars"
```

Invalid:

```python
1player = "David"
```

A variable name cannot begin with a digit.

## Rule 3: Underscores are allowed

Valid:

```python
player_name = "David"
player_age = 20
academy_location = "Ibadan"
```

Underscores are particularly useful for separating words.

## Rule 4: Spaces are not allowed

Invalid:

```python
player name = "David"
```

Python interprets this as incorrectly written code.

Use an underscore instead:

```python
player_name = "David"
```

## Rule 5: Variable names are case-sensitive

Python treats uppercase and lowercase letters as different.

Consider:

```python
name = "David"
Name = "Michael"
NAME = "Samuel"
```

These are three different variable names.

### Important

Avoid using different capitalisation styles unnecessarily.

It makes code harder to read.

## Rule 6: Do not use Python keywords as variable names

Python has reserved words that perform specific functions in the language.

Examples include:

- `if`
- `else`
- `for`
- `while`
- `class`
- `return`
- `import`

You should not use these reserved words as variable names.

Invalid:

```python
if = 20
```

Valid:

```python
player_age = 20
```

# 🧾 07 — PYTHON NAMING CONVENTIONS

Python has a commonly used naming convention called **snake_case**.

In snake_case, words are written in lowercase and separated by underscores.

Examples:

```python
player_name = "David"
player_age = 20
academy_name = "Future Stars Academy"
total_goals = 15
training_sessions = 12
```

This makes variable names easier to read.

### Compare the styles

| Style | Example |
|---|---|
| snake_case | `player_name` |
| camelCase | `playerName` |
| PascalCase | `PlayerName` |
| ALL_CAPS | `PLAYER_NAME` |

For ordinary Python variables, snake_case is the recommended convention.

### Meaningful names matter

Compare these examples:

**Poor naming:**

```python
x = 20
y = "David"
z = 85
```

**Better naming:**

```python
player_age = 20
player_name = "David"
player_score = 85
```

Both versions can work.

However, the second version makes the program easier to understand.

### A useful rule

Choose variable names that answer this question:

**What information does this variable represent?**

# 🔄 08 — CHANGING VARIABLE VALUES

Variables are not necessarily permanent.

You can assign a new value to an existing variable.

This is called reassignment.

### Example 1 — Change a player's age

```python
player_age = 18

print(player_age)

player_age = 19

print(player_age)
```

Output:

```text
18
19
```

What happened?

1. We created `player_age` and assigned it the value `18`.
2. We displayed the value.
3. We reassigned the variable to `19`.
4. We displayed the updated value.

The variable now refers to the new value.

### Example 2 — Update a player's score

```python
player_score = 60

print(player_score)

player_score = 75

print(player_score)

player_score = 90

print(player_score)
```

Output:

```text
60
75
90
```

### Example 3 — Update academy information

```python
academy_name = "Future Stars Academy"

print(academy_name)

academy_name = "Elite Football Academy"

print(academy_name)
```

Output:

```text
Future Stars Academy
Elite Football Academy
```

### Mental model: Updating a labelled box

```text
INITIAL VALUE

player_score
     |
     v
   +----+
   | 60 |
   +----+

UPDATED VALUE

player_score
     |
     v
   +----+
   | 90 |
   +----+
```

The variable name stays the same, but the associated value changes.

### Important lesson

Reassigning a variable does not automatically preserve its previous value.

If you need an earlier value later, you must keep it somewhere else.

# 🧠 11 — UNDERSTANDING REASSIGNMENT WITH CALCULATIONS

This is an important concept.

Consider:

```python
score = 50

score = score + 10

print(score)
```

Output:

```text
60
```

At first glance, this might look strange.

How can `score` equal `score + 10`?

Remember that the single equals sign is an assignment instruction, not a mathematical equality test.

Python evaluates the right-hand side first.

Let's trace it.

**Initial assignment:**

```python
score = 50
```

The variable contains `50`.

**Next instruction:**

```python
score = score + 10
```

Python evaluates:

```text
50 + 10 = 60
```

Then it assigns `60` to `score`.

The variable now contains `60`.

### Another example

```python
goals = 2

goals = goals + 1

print(goals)
```

Output:

```text
3
```

This is useful when you need to update information based on its existing value.

### More examples

```python
players = 20
players = players + 5

print(players)
```

Output:

```text
25
```

```python
budget = 100000
budget = budget - 25000

print(budget)
```

Output:

```text
75000
```

### Shortcut assignment operators

Python also provides shorthand ways to update variables.

For example:

```python
score = 50

score += 10

print(score)
```

Output:

```text
60
```

`score += 10` means:

Take the current value of `score`, add `10`, and assign the result back to `score`.

Other examples:

| Shortcut | Meaning |
|---|---|
| `score += 5` | Add 5 |
| `score -= 5` | Subtract 5 |
| `score *= 2` | Multiply by 2 |
| `score /= 2` | Divide by 2 |

We will study operators properly in Batch 5.

For now, understand that these shortcuts update an existing variable.

# ⚠️ 13 — IMPORTANT: `input()` RETURNS TEXT

This is one of the most important beginner concepts to understand.

When a user enters information using `input()`, Python returns that information as a string.

Even if the user enters a number, the returned value is text.

Consider:

```python
age = input("Enter your age: ")

print(age)
```

If the user enters:

```text
20
```

Python receives the text `"20"`.

It is not automatically treated as the integer `20`.

Why does this matter?

Because text and numbers behave differently.

For example:

```python
number1 = input("Enter first number: ")
number2 = input("Enter second number: ")

print(number1 + number2)
```

If the user enters:

```text
10
20
```

The result may be:

```text
1020
```

Why?

Because Python is joining two pieces of text rather than performing numerical addition.

### How do we solve this?

We can convert the input into a number.

For example:

```python
number1 = int(input("Enter first number: "))
number2 = int(input("Enter second number: "))

print(number1 + number2)
```

If the user enters:

```text
10
20
```

The output becomes:

```text
30
```

Here:

- `input()` receives the information.
- `int()` converts it into an integer.
- The result is stored in the variable.

### Another example

```python
player_age = int(input("Enter player age: "))

print(player_age)
```

If the user enters `18`, the program stores the integer `18`.

### What is `int()`?

`int()` is a built-in Python function used to convert suitable values into integers.

We will study data types and type conversion in more detail in Batch 4.

For now, remember:

**Input entered through `input()` is text by default. Convert it when you need to perform numerical operations.**

# 🧪 14 — VARIABLE TRACING

You must learn to follow how variable values change as a program executes.

Let's practise.

The second assignment replaces the value associated with `age`.

### Example 2

```python

```

Trace:

| Instruction | Value of `score` |
|---|---:|
| `score = 50` | 50 |
| `score = score + 10` | 60 |
| `score = score + 20` | 80 |

Output:

```text
80
```

### Example 3

```python

players = players - 5

players = players + 10

print(players)
```

Trace:

| Instruction | Value of `players` |
|---|---:|
| `players = 30` | 30 |
| `players = players - 5` | 25 |
| `players = players + 10` | 35 |

Output:

```text
35
```

### Example 4 — Multiple variables

```python
a = 10
b = 20

a = b

print(a)
print(b)
```

Output:

```text
20
20
```

Why?

The instruction:

```python
a = b
```

takes the current value of `b` and assigns it to `a`.

It does not swap the two values.

### Example 5 — Understanding reassignment

```python

y = 10

x = y
y = 15

print(x)
print(y)
```

Output:

```text
10
15
```

The value assigned to `x` was copied from `y` before `y` was updated.

This is why tracing instructions in order matters.

# 🚨 15 — COMMON VARIABLE MISTAKES

Let's identify mistakes that beginners commonly make.

## Mistake 1 — Using a variable before assigning it

Incorrect:

```python
print(player_name)

player_name = "David"
```

Python raises a `NameError` because the name has not been assigned before it is used.

Correct:

```python
player_name = "David"

print(player_name)
```

## Mistake 2 — Misspelling a variable name

Incorrect:

```python
player_name = "David"

print(player_nam)
```

The variable name used in `print()` does not match the name that was created.

Correct:

```python
player_name = "David"

print(player_name)
```

## Mistake 3 — Incorrect variable naming

Incorrect:

```python
player name = "David"
```

Variable names cannot contain spaces.

Correct:

```python
player_name = "David"
```

## Mistake 4 — Beginning a variable name with a number

Incorrect:

```python
2players = 50
```

Correct:

```python
players2 = 50
```

## Mistake 5 — Confusing assignment with comparison

Incorrect if the intention is to assign a value:

```python
score == 80
```

Correct:

```python
score = 80
```

## Mistake 6 — Forgetting that input is text

Potentially incorrect:

```python
age = input("Enter age: ")

print(age + 5)
```

This produces a type error because the program attempts to combine text with an integer.

Correct:

```python
age = int(input("Enter age: "))

print(age + 5)
```

## Mistake 7 — Using unclear variable names

Poor:

```python
x = 5000
y = 3
z = x * y
```

Better:

```python
jersey_price = 5000
quantity = 3

total_cost = jersey_price * quantity
```

Both approaches can work, but the second is easier to understand.
