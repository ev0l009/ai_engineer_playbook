# 🧠 SECTION 1 — WHAT ARE DATA TYPES?

## 1.1 Understanding Data

A computer works with information.

That information can represent:

- Names
- Ages
- Prices
- Measurements
- Decisions
- Addresses
- Scores
- Dates
- And much more.

However, not all information behaves the same way.

For example:

```python
player_name = "David"
player_age = 20
player_rating = 8.5
player_is_active = True
```

Look carefully.

Python sees four different kinds of values.

| Variable | Value | Data Type |
|---|---|---|
| `player_name` | `"David"` | String |
| `player_age` | `20` | Integer |
| `player_rating` | `8.5` | Float |
| `player_is_active` | `True` | Boolean |

A **data type** describes the kind of value a variable contains.

It helps Python determine what operations make sense for that value.

### Think of it this way:

Imagine a storage room with different containers.

- One container stores whole numbers.
- Another stores decimal numbers.
- Another stores text.
- Another stores true-or-false values.

You wouldn't treat a player's name like a mathematical score.

Similarly, Python treats different data types differently.

## 1.2 Python's Four Fundamental Beginner Data Types

For this batch, we will concentrate on four important types:

| Data Type | Python Name | Example |
|---|---|---|
| Integer | `int` | `25` |
| Float | `float` | `25.5` |
| String | `str` | `"Python"` |
| Boolean | `bool` | `True` |

These four types will appear repeatedly as you continue learning Python.

# 🔢 SECTION 2 — INTEGERS (`int`)

## 2.1 What Is an Integer?

An **integer** is a whole number without a decimal point.

Examples:

```python
age = 18
score = 95
number_of_players = 22
temperature = -5
```

All these values are integers.

Integers can be:

- Positive: `10`
- Negative: `-10`
- Zero: `0`

They do not contain decimal points.

### Examples of integers

```python
10
25
100
0
-8
-50
```

### Examples that are NOT integers

```python
10.5
25.75
-3.2
```

Those are floating-point numbers, which we will discuss shortly.

## 2.2 Creating Integer Variables

You can store integers inside variables:

```python
player_age = 19
team_size = 11
goals_scored = 3
```

You can also perform calculations using integers.

```python
first_number = 10
second_number = 5

total = first_number + second_number

print(total)
```

Expected output:

```text
15
```

Other mathematical operations work too:

```python
a = 20
b = 4

print(a + b)
print(a - b)
print(a * b)
print(a // b)
```

Expected output:

```text
24
16
80
5
```

Notice the last operation.

`//` performs **floor division**. With positive whole-number operands, it gives the whole-number quotient.

We will explore operators more deeply in Batch 5.

## 2.3 Real-World Integer Examples

Imagine you are developing software for a football academy.

You might store:

```python
player_age = 17
jersey_number = 10
goals_scored = 4
training_days = 5
```

Why are these integers?

Because they represent whole-number quantities in these examples.

A player cannot normally be 17.6 years old in a system that records age as completed years.

A team cannot have 11.5 players.

The data type should make sense for the information being represented.

# 📐 SECTION 3 — FLOATING-POINT NUMBERS (`float`)

## 3.1 What Is a Float?

A **float** is a number that contains a decimal point.

Examples:

```python
height = 1.82
weight = 68.5
price = 1500.75
player_rating = 8.7
```

Python identifies these values as floating-point numbers.

Their type name is:

```python
float
```

## 3.2 Creating Float Variables

Example:

```python
player_height = 1.85
player_weight = 72.5
match_rating = 9.2

print(player_height)
print(player_weight)
print(match_rating)
```

Expected output:

```text
1.85
72.5
9.2
```

## 3.3 Integers vs Floats

Let's compare them.

| Integer (`int`) | Float (`float`) |
|---|---|
| `10` | `10.5` |
| `25` | `25.75` |
| `100` | `100.0` |
| `-5` | `-5.5` |
| `0` | `0.0` |

Notice something interesting:

```python
age = 20
height = 20.0
```

Both variables represent the number twenty.

But their data types are different.

- `20` is an integer.
- `20.0` is a float.

The decimal point matters.

## 3.4 Working with Floats

You can perform mathematical operations using floats.

```python
price = 1500.50
quantity = 3

total = price * quantity

print(total)
```

Expected output:

```text
4501.5
```

You can also combine integers and floats.

```python
number_a = 10
number_b = 2.5

result = number_a + number_b

print(result)
```

Expected output:

```text
12.5
```

Python automatically handles this operation and produces a float.

## 3.5 An Important Float Warning

Computers sometimes represent decimal numbers with tiny precision differences.

For example:

```python
result = 0.1 + 0.2

print(result)
```

You may see:

```text
0.30000000000000004
```

Why?

Because some decimal fractions cannot be represented exactly using the computer's binary floating-point system.

This is called **floating-point precision**.

For now, remember:

> Floats are useful for decimal calculations, but their results are not always perfectly exact.

For applications involving money, developers often use Python's `decimal` module rather than relying on ordinary floats.

You do not need to master that yet.

# 📝 SECTION 4 — STRINGS (`str`)

## 4.1 What Is a String?

A **string** is a sequence of characters.

Strings are used to represent text.

Examples:

```python
name = "Samuel"
country = "Nigeria"
team = "Golden Eagles"
message = "Welcome to Python!"
```

Python identifies strings using:

```python
str
```

Strings can contain:

- Letters
- Numbers
- Spaces
- Symbols
- Punctuation marks

For example:

```python
"Hello"
"Python 3"
"100"
"@academy"
"Welcome, player!"
```

All of these are strings because they are enclosed in quotation marks.

## 4.2 Creating Strings

Python allows you to use single or double quotation marks.

Both are valid:

```python
name = "Samuel"
country = 'Nigeria'
```

You can also use double quotation marks around text containing an apostrophe:

```python
message = "I'm learning Python"
```

Or use single quotation marks around text containing double quotation marks:

```python
message = 'He said "Hello"'
```

This helps avoid quotation mark conflicts.

## 4.3 Numbers Can Also Be Strings

This is VERY important.

Look at these two examples:

```python
age = 20
```

And:

```python
age = "20"
```

They look similar.

But they are different.

The first is an integer.

The second is a string.

Why?

Because `"20"` is enclosed in quotation marks.

Python treats it as text rather than a number.

Compare:

```python
number = 20
text = "20"

print(number + 5)
print(text)
```

Expected output:

```text
25
20
```

Now try:

```python
text = "20"

print(text + 5)
```

You will receive an error.

Why?

Because Python cannot directly add a string and an integer using `+`.

The two values have different data types.

We will learn how to convert between them later.

## 4.4 Joining Strings

You can join strings using the `+` operator.

This is called **string concatenation**.

Example:

```python
first_name = "Samuel"
last_name = "Johnson"

full_name = first_name + " " + last_name

print(full_name)
```

Expected output:

```text
Samuel Johnson
```

Let's break it down:

```python
first_name + " " + last_name
```

Python joins:

1. `"Samuel"`
2. `" "`
3. `"Johnson"`

The result is:

```text
Samuel Johnson
```

## 4.5 Repeating Strings

You can also repeat strings using `*` with an integer.

```python
message = "Hello! "

print(message * 3)
```

Expected output:

```text
Hello! Hello! Hello!
```

This is another example of how the same operator can behave differently depending on the data types involved.

## 4.6 String Formatting with f-Strings

Sometimes you want to combine text with values stored inside variables.

You can use an **f-string**.

Example:

```python
name = "Samuel"
age = 18

print(f"My name is {name} and I am {age} years old.")
```

Expected output:

```text
My name is Samuel and I am 18 years old.
```

Notice the `f` before the quotation mark.

```python
f"..."
```

The curly braces `{}` tell Python to insert the value of a variable or evaluate an expression.

Another example:

```python
player = "David"
goals = 12

print(f"{player} scored {goals} goals this season.")
```

Expected output:

```text
David scored 12 goals this season.
```

You can even include calculations:

```python
price = 500
quantity = 4

print(f"Total cost: {price * quantity}")
```

Expected output:

```text
Total cost: 2000
```

F-strings are extremely useful.

You will use them regularly as you build Python programs.

## 4.7 Strings Are Case-Sensitive

Python treats uppercase and lowercase letters as different characters.

For example:

```python
name1 = "Samuel"
name2 = "samuel"

print(name1 == name2)
```

Expected output:

```text
False
```

Even though the words look almost identical, they are not equal.

Why?

Because `"S"` and `"s"` are different characters.

# ✅ SECTION 5 — BOOLEAN VALUES (`bool`)

## 5.1 What Is a Boolean?

A **Boolean** is a data type that has only two possible values:

```python
True
False
```

Python identifies this data type as:

```python
bool
```

A Boolean represents a truth value.

Something is either true or false.

Examples:

```python
is_registered = True
is_injured = False
has_paid = True
is_active = False
```

Notice something important:

Boolean values do not have quotation marks.

Correct:

```python
is_active = True
```

Also correct:

```python
is_active = False
```

Incorrect if you intend to create a Boolean:

```python
is_active = "True"
```

Why?

Because `"True"` is a string.

`True` is a Boolean.

## 5.2 Why Do We Need Booleans?

Imagine you are building a football academy management system.

You want to know:

- Is the player registered?
- Has the player paid?
- Is the player eligible?
- Is the player currently active?

These questions have true-or-false answers.

You can represent them using Boolean variables.

```python
player_registered = True
payment_complete = False
player_eligible = True

print(player_registered)
print(payment_complete)
print(player_eligible)
```

Expected output:

```text
True
False
True
```

## 5.3 Booleans and Comparisons

Booleans are often produced by comparison operations.

Example:

```python
age = 18

print(age >= 18)
```

Expected output:

```text
True
```

Why?

Because 18 is greater than or equal to 18.

Another example:

```python
score = 45

print(score >= 50)
```

Expected output:

```text
False
```

Because 45 is not greater than or equal to 50.

You can also compare strings:

```python
password = "python123"

print(password == "python123")
```

Expected output:

```text
True
```

The comparison produces a Boolean result.

We will explore comparisons and logical operations in Batch 5.

## 5.4 The Difference Between `True` and `"True"`

This is a common beginner mistake.

```python
a = True
b = "True"

print(type(a))
print(type(b))
```

Expected output:

```text
<class 'bool'>
<class 'str'>
```

The first is a Boolean.

The second is a string.

Never assume that something that looks like a Boolean is automatically a Boolean.

# 🔍 SECTION 6 — CHECKING DATA TYPES WITH `type()`

Now that you understand the four fundamental types, let's learn how to inspect them.

Python provides a built-in function called:

```python
type()
```

It tells you the data type of a value.

## 6.1 Basic Examples

```python
print(type(25))
print(type(3.5))
print(type("Python"))
print(type(True))
```

Expected output:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

Let's understand each result.

| Value | Result |
|---|---|
| `25` | `int` |
| `3.5` | `float` |
| `"Python"` | `str` |
| `True` | `bool` |

## 6.2 Checking Variables

You can also check the data type of a variable.

```python
name = "Samuel"
age = 18
height = 1.82
is_active = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_active))
```

Expected output:

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

## 6.3 Why Is `type()` Important?

Imagine you receive a value from a user.

You are not sure whether it is stored as text or a number.

You can inspect it.

```python
age = "18"

print(type(age))
```

Expected output:

```text
<class 'str'>
```

Although the value looks like a number, Python identifies it as a string.

This is useful when debugging programs.

### Mental Model

Think of `type()` as a label inspector.

You look at a value and ask:

**"What kind of information is this?"**

Python answers.

# 🔄 SECTION 7 — TYPE CONVERSION

This is one of the most important sections in this batch.

You now understand that Python has different data types.

But what happens when you need to change one type into another?

For example:

You ask a user for their age.

They enter:

```text
18
```

You want to add 5 to that age.

How do you do it?

You need to understand **type conversion**.

## 7.1 What Is Type Conversion?

Type conversion means changing a value from one data type to another.

Python provides several built-in functions for this.

| Function | Converts To |
|---|---|
| `int()` | Integer |
| `float()` | Float |
| `str()` | String |
| `bool()` | Boolean |

Let's explore each one.

## 7.2 Converting to Integer with `int()`

The `int()` function converts suitable values into integers.

Example:

```python
number = "25"

converted_number = int(number)

print(converted_number)
print(type(converted_number))
```

Expected output:

```text
25
<class 'int'>
```

Before conversion:

```python
number = "25"
```

The value is a string.

After conversion:

```python
converted_number = int(number)
```

The new value is an integer.

### Another Example

```python
price = 100.8

whole_price = int(price)

print(whole_price)
```

Expected output:

```text
100
```

Important:

`int()` does not round the decimal to the nearest integer.

It removes the fractional part.

For example:

```python
print(int(9.9))
print(int(9.1))
print(int(-9.9))
```

Expected output:

```text
9
9
-9
```

For negative values, the fractional part is removed toward zero.

### Important Warning

Not every string can be converted to an integer.

This works:

```python
age = int("18")
```

This does not:

```python
age = int("eighteen")
```

Python will produce a `ValueError` because `"eighteen"` is not a valid integer representation.

## 7.3 Converting to Float with `float()`

The `float()` function converts suitable values into floating-point numbers.

Example:

```python
number = "12.5"

converted_number = float(number)

print(converted_number)
print(type(converted_number))
```

Expected output:

```text
12.5
<class 'float'>
```

You can also convert an integer into a float:

```python
age = 18

age_as_float = float(age)

print(age_as_float)
```

Expected output:

```text
18.0
```

## 7.4 Converting to String with `str()`

The `str()` function converts suitable values into strings.

Example:

```python
age = 18

age_text = str(age)

print(age_text)
print(type(age_text))
```

Expected output:

```text
18
<class 'str'>
```

Why is this useful?

Imagine you want to combine a number with some text.

```python
age = 18

message = "I am " + str(age) + " years old."

print(message)
```

Expected output:

```text
I am 18 years old.
```

The `str()` function converts the integer into text so it can be joined with the other strings.

You can also use an f-string instead:

```python
age = 18

message = f"I am {age} years old."

print(message)
```

Both approaches are useful.

## 7.5 Converting to Boolean with `bool()`

The `bool()` function converts a value into a Boolean.

Example:

```python
print(bool(1))
print(bool(0))
print(bool(""))
print(bool("Hello"))
```

Expected output:

```text
True
False
False
True
```

Here is the beginner rule:

- Zero is false.
- An empty string is false.
- Non-zero numbers are true.
- Non-empty strings are true.

A few more examples:

```python
print(bool(25))
print(bool(-5))
print(bool(0.0))
print(bool("0"))
print(bool("False"))
```

Expected output:

```text
True
True
False
True
True
```

Pay attention to the last two results.

```python
bool("0")
```

produces `True`.

Why?

Because `"0"` is a non-empty string.

Likewise:

```python
bool("False")
```

also produces `True`.

The string contains characters.

It is not the Boolean value `False`.

### Empty vs Non-Empty

These are false:

```python
bool("")
bool(0)
bool(0.0)
```

These are true:

```python
bool("Hello")
bool("0")
bool(10)
bool(-3)
```

You do not need to memorize every possible case immediately.

Just understand that Python treats certain empty or zero values as false.

# ⌨️ SECTION 8 — DATA TYPES AND USER INPUT

This section connects what you learned in Batch 3 with what you are learning now.

Remember the `input()` function?

It allows a program to receive information from a user.

Example:

```python
name = input("Enter your name: ")

print(name)
```

But there is something important you must understand.

## 8.1 `input()` Returns a String

Even when a user enters a number, `input()` returns a string.

Consider:

```python
age = input("Enter your age: ")

print(type(age))
```

If the user enters:

```text
18
```

The output is:

```text
<class 'str'>
```

Why?

Because `input()` returns text.

It does not automatically determine whether the user entered a number.

## 8.2 The Problem with Numeric Input

Look at this program:

```python
age = input("Enter your age: ")

future_age = age + 5

print(future_age)
```

You might expect the program to add 5 to the age.

But it produces an error.

Why?

Because:

- `age` is a string.
- `5` is an integer.

Python cannot directly add them.

## 8.3 The Solution: Convert the Input

Use `int()`.

```python
age = int(input("Enter your age: "))

future_age = age + 5

print(future_age)
```

Example interaction:

```text
Enter your age: 18
23
```

Let's break this down.

```python
input("Enter your age: ")
```

Receives text from the user.

```python
int(...)
```

Converts that text into an integer.

```python
age = ...
```

Stores the converted value inside the variable.

This is an important pattern:

```python
number = int(input("Enter a number: "))
```

## 8.4 Accepting Decimal Input

What if you need a decimal number?

Use `float()`.

```python
height = float(input("Enter your height: "))

print(f"Your height is {height} metres.")
```

Example interaction:

```text
Enter your height: 1.85
Your height is 1.85 metres.
```

## 8.5 Accepting Text Input

For names and other text, you normally do not need conversion.

```python
name = input("Enter your name: ")

print(f"Welcome, {name}!")
```

## 8.6 A Complete Input Example

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))
height = float(input("Enter your height: "))

print()
print("PLAYER INFORMATION")
print("------------------")
print(f"Name: {name}")
print(f"Age: {age}")
print(f"Height: {height} metres")
```

Example interaction:

```text
Enter your name: Samuel
Enter your age: 18
Enter your height: 1.82

PLAYER INFORMATION
------------------
Name: Samuel
Age: 18
Height: 1.82 metres
```

This small program uses three different data types:

- `str`
- `int`
- `float`

You are beginning to combine concepts into real programs.

# ⚠️ SECTION 9 — COMMON DATA TYPE MISTAKES

Every beginner makes mistakes.

The goal is not to avoid every mistake.

The goal is to understand why mistakes happen and learn how to fix them.

Let's examine some common ones.

## Mistake 1 — Treating a Number as Text

Incorrect:

```python
age = "20"

print(age + 5)
```

Problem:

You are trying to add a string and an integer.

Correction:

```python
age = int("20")

print(age + 5)
```

Output:

```text
25
```

## Mistake 2 — Forgetting to Convert Input

Incorrect:

```python
number = input("Enter a number: ")

result = number * 2
```

This does not perform ordinary numeric multiplication.

If the user enters `5`, the result is string repetition:

```text
55
```

Why?

Because `number` is a string.

Correction:

```python
number = int(input("Enter a number: "))

result = number * 2

print(result)
```

If the user enters `5`, the output is:

```text
10
```

## Mistake 3 — Using the Wrong Conversion

Incorrect:

```python
height = int(input("Enter your height: "))
```

If the user enters:

```text
1.85
```

Python produces a `ValueError`.

Why?

Because `"1.85"` cannot be converted directly into an integer using `int()`.

Correction:

```python
height = float(input("Enter your height: "))
```

## Mistake 4 — Confusing `True` with `"True"`

Incorrect if you need a Boolean:

```python
is_active = "True"
```

Correct:

```python
is_active = True
```

The first is a string.

The second is a Boolean.

## Mistake 5 — Trying to Convert Words into Numbers

Incorrect:

```python
age = int("twenty")
```

Problem:

The word `"twenty"` is not a numeric string that `int()` can understand.

Correction:

```python
age = 20
```

Or accept numeric input from the user:

```python
age = int(input("Enter your age: "))
```

## Mistake 6 — Assuming `int()` Rounds Numbers

Incorrect assumption:

```python
number = 7.9

print(int(number))
```

Some beginners expect:

```text
8
```

Actual output:

```text
7
```

`int()` removes the fractional part. It does not round to the nearest whole number.

## Mistake 7 — Using Quotation Marks Around Boolean Values

Incorrect:

```python
is_registered = "False"
```

If you intend to store a Boolean:

```python
is_registered = False
```

Remember:

Quotation marks turn the content into a string.

## Mistake 8 — Converting Invalid User Input

Consider:

```python
age = int(input("Enter your age: "))
```

What happens if the user enters:

```text
hello
```

Python cannot convert `"hello"` into an integer.

It raises a `ValueError`.

For now, understand that programs should eventually learn to handle invalid input rather than crashing.

We will practise more error handling in later stages.
