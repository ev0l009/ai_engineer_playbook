# 🧠 SECTION 1 — WHAT ARE OPERATORS?

## 1.1 Understanding Operators

An operator is something Python uses to perform an action.

Consider:

```python
number_one = 10
number_two = 5

result = number_one + number_two

print(result)
```

Output:

```text
15
```

Let's break it down:

```python
number_one + number_two
```

- `number_one` is an operand.
- `+` is the operator.
- `number_two` is another operand.

An **operand** is a value or variable that an operator works on.

In this example:

```text
10 + 5
```

The operator is `+`.

The operands are `10` and `5`.

## 1.2 Types of Python Operators

Python provides several categories of operators.

| Category | Purpose |
|---|---|
| Arithmetic | Perform mathematical calculations |
| Assignment | Assign or update variable values |
| Comparison | Compare two values |
| Logical | Combine or reverse conditions |
| Membership | Check whether something exists in a collection |
| Identity | Check whether two references point to the same object |

We will explore each category.

# 🔢 SECTION 2 — ARITHMETIC OPERATORS

Arithmetic operators are used to perform mathematical calculations.

These are the operators you will probably use most often when starting out.

Python has seven commonly used arithmetic operators.

| Operator | Name | Purpose |
|---|---|---|
| `+` | Addition | Adds values |
| `-` | Subtraction | Subtracts values |
| `*` | Multiplication | Multiplies values |
| `/` | Division | Divides values |
| `//` | Floor Division | Divides and rounds the quotient down |
| `%` | Modulus | Returns the remainder |
| `**` | Exponentiation | Raises a number to a power |

Let's explore them.

## 2.1 Addition (`+`)

The addition operator adds two or more values.

Example:

```python
a = 10
b = 5

result = a + b

print(result)
```

Output:

```text
15
```

You can add several values:

```python
a = 10
b = 5
c = 3

total = a + b + c

print(total)
```

Output:

```text
18
```

### Real-World Example

Imagine a player scores 12 goals in one competition and 8 in another.

```python
league_goals = 12
cup_goals = 8

total_goals = league_goals + cup_goals

print(f"Total goals: {total_goals}")
```

Output:

```text
Total goals: 20
```

## 2.2 Subtraction (`-`)

Subtraction removes one value from another.

```python
a = 20
b = 8

result = a - b

print(result)
```

Output:

```text
12
```

### Real-World Example

A team has a budget of ₦100,000 and spends ₦35,000.

```python
budget = 100000
expenses = 35000

remaining_budget = budget - expenses

print(remaining_budget)
```

Output:

```text
65000
```

## 2.3 Multiplication (`*`)

Multiplication calculates the product of two values.

```python
a = 6
b = 7

result = a * b

print(result)
```

Output:

```text
42
```

### Real-World Example

An academy purchases 15 footballs.

Each football costs ₦8,000.

```python
football_price = 8000
quantity = 15

total_cost = football_price * quantity

print(total_cost)
```

Output:

```text
120000
```

## 2.4 Division (`/`)

Division divides one value by another.

```python
a = 20
b = 4

result = a / b

print(result)
```

Output:

```text
5.0
```

Notice something important.

Even though both values are integers, ordinary division `/` returns a float.

Another example:

```python
print(10 / 3)
```

Output:

```text
3.3333333333333335
```

### Real-World Example

An academy spends ₦50,000 equally on five training sessions.

```python
total_budget = 50000
number_of_sessions = 5

cost_per_session = total_budget / number_of_sessions

print(cost_per_session)
```

Output:

```text
10000.0
```

### Important Warning: Division by Zero

This is valid:

```python
print(10 / 2)
```

This is not:

```python
print(10 / 0)
```

Python raises:

```text
ZeroDivisionError
```

You cannot divide a number by zero in ordinary Python arithmetic.

Always consider whether the divisor could be zero.

## 2.5 Floor Division (`//`)

Floor division divides two numbers and rounds the result down to the nearest whole number.

Example:

```python
a = 17
b = 5

result = a // b

print(result)
```

Output:

```text
3
```

Why?

Because:

```text
17 / 5 = 3.4
```

Floor division returns the floor of the result:

```text
3
```

Compare:

```python
print(17 / 5)
print(17 // 5)
```

Output:

```text
3.4
3
```

### Important Detail

Floor division does not simply remove the decimal part.

It rounds down toward negative infinity.

Example:

```python
print(-17 // 5)
```

Output:

```text
-4
```

Because:

```text
-17 / 5 = -3.4
```

The floor is `-4`.

For now, remember:

- `/` gives ordinary division.
- `//` gives floor division.

## 2.6 Modulus (`%`)

The modulus operator returns the remainder after division.

Example:

```python
a = 17
b = 5

result = a % b

print(result)
```

Output:

```text
2
```

Why?

Because:

```text
17 ÷ 5 = 3 remainder 2
```

Therefore:

```python
17 % 5
```

returns:

```text
2
```

### Another Example

```python
print(10 % 3)
print(20 % 6)
print(15 % 4)
```

Output:

```text
1
2
3
```

### Why Is Modulus Useful?

One common use is checking whether a number is even or odd.

A number is even if dividing it by 2 leaves a remainder of zero.

```python
number = 10

print(number % 2)
```

Output:

```text
0
```

An odd number leaves a remainder of one.

```python
number = 7

print(number % 2)
```

Output:

```text
1
```

You can use this to identify even and odd numbers.

```python
number = 15

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

Output:

```text
Odd number
```

You will understand the `if` and `else` statements properly in Batch 8.

For now, focus on the arithmetic.

### Another Practical Use: Grouping Players

Imagine you have 23 players and want to form groups of 5.

```python
players = 23
group_size = 5

complete_groups = players // group_size
remaining_players = players % group_size

print(complete_groups)
print(remaining_players)
```

Output:

```text
4
3
```

You can create four complete groups, with three players remaining.

## 2.7 Exponentiation (`**`)

Exponentiation raises a number to a power.

Example:

```python
result = 2 ** 3

print(result)
```

Output:

```text
8
```

Why?

Because:

```text
2 × 2 × 2 = 8
```

Another example:

```python
print(5 ** 2)
print(3 ** 3)
print(10 ** 2)
```

Output:

```text
25
27
100
```

### Real-World Example

Suppose you want to calculate the area of a square.

Formula:

```text
Area = Side × Side
```

You can also write:

```text
Area = Side ** 2
```

Python:

```python
side = 6

area = side ** 2

print(area)
```

Output:

```text
36
```

# 📦 SECTION 3 — ASSIGNMENT OPERATORS

Assignment operators are used to assign values to variables.

You already know the basic assignment operator:

```python
=
```

But Python provides several other assignment operators that make updating variables easier.

## 3.1 Basic Assignment (`=`)

Example:

```python
score = 10
```

This stores the value `10` inside the variable `score`.

Remember:

`=` means assignment.

It does not mean "is equal to" in the mathematical comparison sense.

## 3.2 Addition Assignment (`+=`)

This adds a value to an existing variable and stores the result back in that variable.

Example:

```python
score = 10

score += 5

print(score)
```

Output:

```text
15
```

This is equivalent to:

```python
score = score + 5
```

Both perform the same update.

### Football Example

A player currently has 8 goals.

They score another 2 goals.

```python
goals = 8

goals += 2

print(goals)
```

Output:

```text
10
```

## 3.3 Subtraction Assignment (`-=`)

Subtracts a value from a variable and stores the result.

```python
budget = 100000

budget -= 25000

print(budget)
```

Output:

```text
75000
```

Equivalent to:

```python
budget = budget - 25000
```

## 3.4 Multiplication Assignment (`*=`)

Multiplies a variable by a value and stores the result.

```python
number = 5

number *= 3

print(number)
```

Output:

```text
15
```

Equivalent to:

```python
number = number * 3
```

## 3.5 Division Assignment (`/=`)

Divides a variable by a value and stores the result.

```python
number = 20

number /= 4

print(number)
```

Output:

```text
5.0
```

Notice that the result is a float.

## 3.6 Floor Division Assignment (`//=`)

```python
number = 17

number //= 5

print(number)
```

Output:

```text
3
```

## 3.7 Modulus Assignment (`%=`)

```python
number = 17

number %= 5

print(number)
```

Output:

```text
2
```

## 3.8 Exponentiation Assignment (`**=`)

```python
number = 3

number **= 2

print(number)
```

Output:

```text
9
```

## 3.9 Assignment Operators Summary

| Operator | Example | Equivalent |
|---|---|---|
| `=` | `x = 10` | Assign 10 |
| `+=` | `x += 5` | `x = x + 5` |
| `-=` | `x -= 5` | `x = x - 5` |
| `*=` | `x *= 5` | `x = x * 5` |
| `/=` | `x /= 5` | `x = x / 5` |
| `//=` | `x //= 5` | `x = x // 5` |
| `%=` | `x %= 5` | `x = x % 5` |
| `**=` | `x **= 5` | `x = x ** 5` |

### Mental Model: Updating a Scoreboard

Imagine a scoreboard.

A player begins with 10 points.

You don't need to calculate the new total manually and create another variable.

You can simply update the existing variable.

```python
score = 10

score += 5

print(score)
```

The variable changes from 10 to 15.

This is especially useful when building programs that track changing information.

# ⚖️ SECTION 4 — COMPARISON OPERATORS

Comparison operators compare two values.

They produce a Boolean result:

```python
True
```

Or:

```python
False
```

These operators are extremely important because programs often need to make decisions.

For example:

- Is the player old enough?
- Is the score high enough?
- Is the budget sufficient?
- Are two values equal?
- Is the player below the required age?

Python provides six common comparison operators.

| Operator | Meaning |
|---|---|
| `==` | Equal to |
| `!=` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

Let's explore them.

## 4.1 Equal To (`==`)

Checks whether two values are equal.

```python
a = 10
b = 10

print(a == b)
```

Output:

```text
True
```

Another example:

```python
age = 18

print(age == 20)
```

Output:

```text
False
```

Because 18 is not equal to 20.

### Important: `=` vs `==`

These are different.

Assignment:

```python
age = 18
```

Comparison:

```python
age == 18
```

The first stores a value.

The second checks whether two values are equal.

This is one of the most important distinctions in beginner Python.

## 4.2 Not Equal To (`!=`)

Checks whether two values are different.

```python
a = 10
b = 5

print(a != b)
```

Output:

```text
True
```

Because 10 is not equal to 5.

Another example:

```python
password = "python123"

print(password != "admin")
```

Output:

```text
True
```

## 4.3 Greater Than (`>`)

Checks whether the left value is greater than the right value.

```python
age = 20

print(age > 18)
```

Output:

```text
True
```

But:

```python
age = 16

print(age > 18)
```

Output:

```text
False
```

## 4.4 Less Than (`<`)

Checks whether the left value is smaller than the right value.

```python
score = 40

print(score < 50)
```

Output:

```text
True
```

## 4.5 Greater Than or Equal To (`>=`)

Checks whether a value is greater than or equal to another value.

```python
age = 18

print(age >= 18)
```

Output:

```text
True
```

This is true because the values are equal.

Another example:

```python
score = 85

print(score >= 80)
```

Output:

```text
True
```

## 4.6 Less Than or Equal To (`<=`)

Checks whether a value is less than or equal to another value.

```python
age = 17

print(age <= 18)
```

Output:

```text
True
```

### Comparison Summary

Suppose:

```python
a = 10
b = 5
```

Then:

| Expression | Result |
|---|---|
| `a == b` | `False` |
| `a != b` | `True` |
| `a > b` | `True` |
| `a < b` | `False` |
| `a >= b` | `True` |
| `a <= b` | `False` |

## 4.7 Comparing Strings

Comparison operators can also work with strings.

Example:

```python
name_one = "Samuel"
name_two = "Samuel"

print(name_one == name_two)
```

Output:

```text
True
```

But:

```python
name_one = "Samuel"
name_two = "samuel"

print(name_one == name_two)
```

Output:

```text
False
```

Remember that strings are case-sensitive.

Python also supports ordering comparisons between strings using their character ordering, but don't confuse that with alphabetical sorting in every language or locale.

For now, focus on equality and inequality comparisons with strings.

## 4.8 Comparison Operators in Real Programs

Imagine an academy requires players to be at least 16 years old.

```python
player_age = 17

minimum_age = 16

eligible = player_age >= minimum_age

print(eligible)
```

Output:

```text
True
```

The comparison produces a Boolean value.

This is the foundation of decision-making in programming.

# 🧠 SECTION 5 — LOGICAL OPERATORS

Logical operators allow you to combine conditions.

Imagine a football academy has this registration rule:

A player can join if:

- The player is at least 16 years old.
- The player has a rating of at least 7.0.

Checking only one condition is not enough.

You need to check both.

This is where logical operators become useful.

Python has three main logical operators:

| Operator | Purpose |
|---|---|
| `and` | True when both conditions are true |
| `or` | True when at least one condition is true |
| `not` | Reverses a Boolean value |

Let's explore each one.

## 5.1 The `and` Operator

The `and` operator returns `True` only when both conditions are true.

Example:

```python
age = 18
rating = 8.5

result = age >= 16 and rating >= 7.0

print(result)
```

Output:

```text
True
```

Why?

Condition 1:

```python
age >= 16
```

Result:

```text
True
```

Condition 2:

```python
rating >= 7.0
```

Result:

```text
True
```

Both conditions are true.

Therefore:

```python
True and True
```

produces:

```text
True
```

### The AND Truth Table

| Condition A | Condition B | A and B |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

Remember:

**AND requires both conditions to be true.**

### Example: Academy Registration

```python
age = 17
rating = 6.5

eligible = age >= 16 and rating >= 7.0

print(eligible)
```

Output:

```text
False
```

The player meets the age requirement but does not meet the rating requirement.

Both are required.

## 5.2 The `or` Operator

The `or` operator returns `True` if at least one condition is true.

Example:

```python
has_talent = True
has_experience = False

result = has_talent or has_experience

print(result)
```

Output:

```text
True
```

Why?

At least one condition is true.

### The OR Truth Table

| Condition A | Condition B | A or B |
|---|---|---|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

Remember:

**OR needs at least one condition to be true.**

### Example: Academy Trial

A player can be invited to a trial if they have either:

- A recommendation.
- Previous academy experience.

```python
has_recommendation = False
has_experience = True

invited = has_recommendation or has_experience

print(invited)
```

Output:

```text
True
```

Only one condition needs to be true.

## 5.3 The `not` Operator

The `not` operator reverses a Boolean value.

If a value is `True`, `not` makes it `False`.

If a value is `False`, `not` makes it `True`.

Example:

```python
is_injured = False

print(not is_injured)
```

Output:

```text
True
```

Another example:

```python
is_registered = True

print(not is_registered)
```

Output:

```text
False
```

### The NOT Truth Table

| Condition | not Condition |
|---|---|
| True | False |
| False | True |

### Real-World Example

You want to check whether a player is not registered.

```python
is_registered = False

not_registered = not is_registered

print(not_registered)
```

Output:

```text
True
```

## 5.4 Combining Multiple Logical Operators

You can combine conditions using more than one logical operator.

Example:

```python
age = 18
rating = 8.5
is_registered = True

eligible = age >= 16 and rating >= 7.0 and is_registered

print(eligible)
```

Output:

```text
True
```

The player must:

- Be at least 16.
- Have a rating of at least 7.0.
- Be registered.

All three conditions must be true.

### Another Example

```python
age = 15
has_recommendation = True
has_experience = False

can_attend_trial = age >= 16 or has_recommendation or has_experience

print(can_attend_trial)
```

Output:

```text
True
```

The recommendation makes the overall expression true.

## 5.5 Understanding Logical Operators with Simple English

Think about these statements.

### AND

"I will attend training if I have my boots AND my training kit."

Both must be available.

### OR

"I will attend training if I have my boots OR my training kit."

At least one condition must be true for this expression to be true.

### NOT

"I am NOT injured."

This reverses the meaning of the injury condition.

# 🔎 SECTION 6 — MEMBERSHIP OPERATORS

Membership operators check whether a value exists inside a collection.

Python has two membership operators:

```python
in
not in
```

You will use these with strings, lists, tuples, sets, and other collections.

We will explore lists and collections more deeply later.

For now, understand the basic idea.

## 6.1 The `in` Operator

The `in` operator checks whether an item exists in something.

Example:

```python
name = "Samuel"

print("S" in name)
```

Output:

```text
True
```

Why?

Because the character `"S"` exists inside `"Samuel"`.

Another example:

```python
team = "Golden Eagles"

print("Eagles" in team)
```

Output:

```text
True
```

## 6.2 Checking Whether a Word Exists in a Sentence

```python
message = "I am learning Python programming"

print("Python" in message)
```

Output:

```text
True
```

But:

```python
print("Java" in message)
```

Output:

```text
False
```

## 6.3 The `not in` Operator

Checks whether a value does not exist in a collection.

```python
message = "Welcome to Python"

print("Java" not in message)
```

Output:

# 🪪 SECTION 7 — IDENTITY OPERATORS

Python has two identity operators:

```python
is
is not
```

These operators check whether two references point to the same object.

This is different from checking whether two values are equal.

Let's understand that distinction carefully.

## 7.1 Equality vs Identity

Equality uses:

```python
==
```

Identity uses:

```python
is
```

Consider:

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)
print(a is b)
```

Output:

```text
True
False
```

Why?

The lists contain the same values.

Therefore:

```python
a == b
```

is `True`.

But they are two separate list objects.

Therefore:

```python
a is b
```

is `False`.

### Mental Model

Imagine two notebooks.

Both contain exactly the same notes.

The contents are equal.

But they are two different physical notebooks.

That is the difference between equality and identity.

## 7.2 The `is` Operator

Checks whether two variables refer to the same object.

Example:

```python
a = [1, 2, 3]
b = a

print(a is b)
```

Output:

```text
True
```

Why?

Because `b` refers to the same list object as `a`.

## 7.3 The `is not` Operator

Checks whether two references do not point to the same object.

```python
a = [1, 2]
b = [1, 2]

print(a is not b)
```

Output:

```text
True
```

They contain equal values, but they are different objects.

## 7.4 Important Beginner Rule

When checking whether two ordinary values are equal, normally use:

```python
==
```

When checking whether something is specifically `None`, use:

```python
is
```

Example:

```python
player_name = None

print(player_name is None)
```

Output:

```text
True
```

`None` represents the absence of a value.

You will encounter it more often as your Python skills develop.

For now, remember:

- `==` checks equality.
- `is` checks identity.

Do not use `is` as a replacement for `==` when comparing ordinary values.

# 🧮 SECTION 8 — OPERATOR PRECEDENCE

What happens when a mathematical expression contains several operators?

For example:

```python
result = 10 + 5 * 2
```

Should Python:

1. Add first, then multiply?
2. Multiply first, then add?

Python follows rules called **operator precedence**.

These rules determine the order in which operations are performed.

## 8.1 Basic Mathematical Order

Consider:

```python
result = 10 + 5 * 2

print(result)
```

Output:

```text
20
```

Why?

Python performs multiplication before addition.

First:

```text
5 × 2 = 10
```

Then:

```text
10 + 10 = 20
```

## 8.2 Using Parentheses

Parentheses allow you to control the order of operations.

Example:

```python
result = (10 + 5) * 2

print(result)
```

Output:

```text
30
```

Why?

Python performs the operation inside the parentheses first.

```text
10 + 5 = 15
```

Then:

```text
15 × 2 = 30
```

Compare:

```python
print(10 + 5 * 2)
print((10 + 5) * 2)
```

Output:

```text
20
30
```

## 8.3 Common Operator Precedence

Here is a simplified beginner reference.

| Priority | Operators | Description |
|---|---|---|
| 1 | `()` | Parentheses |
| 2 | `**` | Exponentiation |
| 3 | `+x`, `-x` | Unary positive and negative |
| 4 | `*`, `/`, `//`, `%` | Multiplication and division |
| 5 | `+`, `-` | Addition and subtraction |
| 6 | Comparisons | `==`, `!=`, `>`, `<`, `>=`, `<=`, `in`, `is` |
| 7 | `not` | Logical NOT |
| 8 | `and` | Logical AND |
| 9 | `or` | Logical OR |

This is a simplified guide, not the complete Python precedence table.

For now, it is enough to understand the most common rules.

## 8.4 More Examples

Example 1:

```python
print(2 + 3 * 4)
```

Output:

```text
14
```

Example 2:

```python
print((2 + 3) * 4)
```

Output:

```text
20
```

Example 3:

```python
print(2 ** 3 + 4)
```

Output:

```text
12
```

First:

```text
2 ** 3 = 8
```

Then:

```text
8 + 4 = 12
```

Example 4:

```python
print(20 / 5 + 3)
```

Output:

```text
7.0
```

First:

```text
20 / 5 = 4.0
```

Then:

```text
4.0 + 3 = 7.0
```

## 8.5 Parentheses Make Code Clearer

Even when you understand precedence, parentheses can make calculations easier to read.

For example:

```python
total = (price * quantity) + delivery_fee
```

This makes your intention clear.

A good programmer writes code that other people can understand.

# ⚠️ SECTION 10 — COMMON OPERATOR MISTAKES

Let's examine mistakes that beginners frequently make.

## Mistake 1 — Confusing `=` and `==`

Incorrect:

```python
age = 18

if age = 18:
    print("Eligible")
```

Problem:

`=` assigns a value.

`==` compares two values.

Correction:

```python
age = 18

if age == 18:
    print("Eligible")
```

## Mistake 2 — Dividing by Zero

Incorrect:

```python
result = 20 / 0
```

Problem:

Python raises `ZeroDivisionError`.

Correction:

Ensure the divisor is not zero before performing the calculation.

```python
divisor = 5

if divisor != 0:
    result = 20 / divisor
    print(result)
```

## Mistake 3 — Forgetting Operator Precedence

Consider:

```python
result = 10 + 5 * 2
```

Some beginners expect `30`.

Actual result:

```text
20
```

Correction if you want 30:

```python
result = (10 + 5) * 2
```

## Mistake 4 — Mixing Strings and Numbers

Incorrect:

```python
number = "10"

result = number + 5
```

Problem:

A string and integer cannot be directly added.

Correction:

```python
number = int("10")

result = number + 5

print(result)
```

## Mistake 5 — Incorrect Logical Conditions

Suppose a player must be at least 16 years old and have a rating of at least 7.

Incorrect:

```python
eligible = age >= 16 or rating >= 7
```

If both requirements must be met, `or` is incorrect.

Correction:

```python
eligible = age >= 16 and rating >= 7
```

## Mistake 6 — Using `is` Instead of `==`

Incorrect for ordinary value comparison:

```python
age = 18

print(age is 18)
```

Use:

```python
print(age == 18)
```

`is` checks object identity, not ordinary value equality.

## Mistake 7 — Forgetting That Comparison Operators Return Booleans

Example:

```python
age = 18

result = age >= 16

print(result)
```

Output:

```text
True
```

The variable `result` does not contain the number 18.

It contains a Boolean value.

```python
total = goals + assists
```

