# 🧠 SECTION 1 — UNDERSTANDING INPUT AND OUTPUT

## 1.1 What Is Input?

Input is information supplied to a program.

For example, imagine a program that asks for your name.

You enter:

```text
Samuel
```

The program receives that information.

That information is called input.

Other examples include:

- Your age.
- Your email address.
- Your examination score.
- Your favourite football club.
- The number of players in a team.

A program can receive information from different sources, but in this batch, we will focus on receiving information directly from a user through the keyboard.

## 1.2 What Is Output?

Output is information a program produces or displays.

For example:

```text
Welcome to Python!
```

Or:

```text
Your total score is 85.
```

Output allows users to see what a program has done.

## 1.3 Understanding the Relationship

Consider a simple program:

```python
name = input("Enter your name: ")

print("Welcome", name)
```

The program performs two actions.

**Input:**

```text
Enter your name: Samuel
```

**Output:**

```text
Welcome Samuel
```

The process looks like this:

```text
       USER
         |
         |
         v
   Enters information
         |
         |
         v
    PYTHON PROGRAM
         |
         |
         v
    Processes data
         |
         |
         v
    Displays result
         |
         |
         v
       OUTPUT
```

### The Big Idea

Input allows information to enter a program.

Output allows information to leave a program in a form the user can see.

Without input, many programs cannot respond to the user's personal information.

Without output, users may not know what the program has done.

# 🖥️ SECTION 2 — DISPLAYING INFORMATION WITH `print()`

The `print()` function displays information on the screen.

You have already used it in previous batches.

Let's understand it more deeply.

## 2.1 Displaying Text

Example:

```python
print("Hello, World!")
```

Output:

```text
Hello, World!
```

Text must be placed inside quotation marks.

You can use either single or double quotation marks.

```python
print("Hello Python")
print('Hello Python')
```

Both are valid.

## 2.2 Displaying Numbers

You can display numbers without quotation marks.

```python
print(100)
print(25.5)
print(-10)
```

Output:

```text
100
25.5
-10
```

Notice the difference:

```python
print(100)
```

Displays a number.

But:

```python
print("100")
```

Displays text containing the characters `100`.

They look similar on the screen, but their data types are different.

## 2.3 Displaying Variables

You can display the value stored inside a variable.

```python
name = "Samuel"
age = 20

print(name)
print(age)
```

Output:

```text
Samuel
20
```

Python retrieves the values stored in the variables and displays them.

## 2.4 Displaying Multiple Values

The `print()` function can display multiple values separated by commas.

```python
name = "Samuel"
age = 20
club = "Arsenal"

print(name, age, club)
```

Output:

```text
Samuel 20 Arsenal
```

Python automatically inserts spaces between the values by default.

You can also write:

```python
print("Name:", name)
print("Age:", age)
print("Club:", club)
```

Output:

```text
Name: Samuel
Age: 20
Club: Arsenal
```

This is more readable.

## 2.5 Displaying Calculations

You can perform calculations directly inside `print()`.

```python
print(10 + 5)
print(20 - 8)
print(6 * 7)
print(100 / 4)
```

Output:

```text
15
12
42
25.0
```

You can also display calculations involving variables.

```python
goals = 12
assists = 8

print(goals + assists)
```

Output:

```text
20
```

## 2.6 Printing Text and Calculations Together

```python
goals = 12
assists = 8

print("Total contributions:", goals + assists)
```

Output:

```text
Total contributions: 20
```

This is useful when you want to display meaningful results.

## 2.7 The `sep` Parameter

By default, `print()` separates multiple values with a space.

Example:

```python
print("Python", "is", "fun")
```

Output:

```text
Python is fun
```

You can change the separator using `sep`.

Example:

```python
print("2026", "11", "09", sep="-")
```

Output:

```text
2026-11-09
```

Another example:

```python
print("Samuel", "David", "Michael", sep=", ")
```

Output:

```text
Samuel, David, Michael
```

The `sep` parameter controls what appears between the values.

### More Examples

```python
print("A", "B", "C", sep="|")
print("10", "20", "30", sep=" - ")
print("Python", "Programming", sep=" ")
```

Output:

```text
A|B|C
10 - 20 - 30
Python Programming
```

## 2.8 The `end` Parameter

By default, `print()` moves to a new line after displaying information.

Example:

```python
print("Hello")
print("World")
```

Output:

```text
Hello
World
```

But you can change this behaviour using `end`.

Example:

```python
print("Hello", end=" ")
print("World")
```

Output:

```text
Hello World
```

The first `print()` does not move to a new line.

Instead, it ends with a space.

Another example:

```python
print("Loading", end="...")
print("Complete")
```

Output:

```text
Loading...Complete
```

### Using `end` with a New Line

You can also use:

```python
print("First line", end="\n")
print("Second line")
```

Output:

```text
First line
Second line
```

`\n` represents a newline character.

You will explore escape characters more deeply in the Strings batch.

### Difference Between `sep` and `end`

| Parameter | Purpose |
|---|---|
| `sep` | Controls the separator between multiple values |
| `end` | Controls what is printed at the end of the output |

Example:

```python
print("A", "B", "C", sep="-", end="!")
```

Output:

```text
A-B-C!
```

# ⌨️ SECTION 3 — UNDERSTANDING `input()`

Now let's learn how to receive information from users.

Python provides the `input()` function.

## 3.1 Basic Input

Example:

```python
name = input("Enter your name: ")
```

When Python reaches this line, it displays:

```text
Enter your name:
```

The program waits for the user to type something.

Suppose the user enters:

```text
Samuel
```

Python receives that information.

The value is then stored inside the variable `name`.

### Important

The `input()` function pauses the program until the user provides input and presses Enter.

This makes programs interactive.

## 3.2 Understanding the Input Prompt

Consider:

```python
age = input("Enter your age: ")
```

The text:

```text
Enter your age:
```

is called the prompt.

It tells the user what information to enter.

The variable:

```python
age
```

stores whatever the user enters.

## 3.3 Input Without a Prompt

You can also use `input()` without a message.

```python
name = input()

print(name)
```

If the user enters:

```text
Samuel
```

Output:

```text
Samuel
```

However, prompts are usually better because they tell users what information is expected.

## 3.4 Input Is Stored as a Value

Example:

```python
name = input("Enter your name: ")

print("Welcome", name)
```

Suppose the user enters:

```text
David
```

Output:

```text
Welcome David
```

The input becomes the value stored in `name`.

# 🔢 SECTION 5 — INPUT AND DATA TYPES

This is one of the most important concepts in this batch.

Pay close attention.

## 5.1 The Important Rule

**The `input()` function always returns a string.**

Even if the user enters a number, Python receives it as text.

Example:

```python
age = input("Enter your age: ")

print(type(age))
```

Suppose the user enters:

```text
18
```

Output:

```text
<class 'str'>
```

Why?

Because `input()` returns a string.

The value looks like a number, but Python treats it as text.

## 5.2 Understanding the Problem

Consider:

```python
number_one = input("Enter first number: ")
number_two = input("Enter second number: ")

result = number_one + number_two

print(result)
```

Suppose the user enters:

```text
10
5
```

The output is:

```text
105
```

Why didn't Python calculate 15?

Because both inputs are strings.

When you use `+` with strings, Python joins them together.

This is called string concatenation.

Python sees:

```python
"10" + "5"
```

And produces:

```text
105
```

It does not see:

```python
10 + 5
```

This is why converting input is important.

# 🔄 SECTION 6 — CONVERTING INPUT WITH `int()` AND `float()`

Python provides conversion functions that allow you to change values from one data type to another.

The two most important ones for this batch are:

```python
int()
```

And:

```python
float()
```

## 6.1 Using `int()`

The `int()` function converts a suitable value into an integer.

Example:

```python
age = int(input("Enter your age: "))

print(age)
```

Suppose the user enters:

```text
18
```

Python performs two actions:

1. `input()` receives `"18"` as a string.
2. `int()` converts `"18"` into the integer `18`.

Now the variable `age` contains an integer.

Check:

```python
age = int(input("Enter your age: "))

print(type(age))
```

Example input:

```text
18
```

Output:

```text
<class 'int'>
```

## 6.2 Performing Calculations with Integer Input

Now let's fix our earlier calculator.

```python
number_one = int(input("Enter first number: "))
number_two = int(input("Enter second number: "))

result = number_one + number_two

print("Total:", result)
```

Example interaction:

```text
Enter first number: 10
Enter second number: 5
Total: 15
```

This time, Python performs numeric addition.

## 6.3 Important: `int()` Does Not Accept Every Number Format

This works:

```python
number = int("25")
```

This also works:

```python
number = int("-10")
```

But this does not:

```python
number = int("25.5")
```

Python raises a `ValueError`.

Why?

Because `"25.5"` is a decimal-formatted string, not an integer-formatted string.

If you need to accept decimal numbers, use `float()`.

## 6.4 Using `float()`

The `float()` function converts a suitable value into a floating-point number.

Example:

```python
rating = float(input("Enter your rating: "))

print(rating)
```

Suppose the user enters:

```text
8.5
```

Output:

```text
8.5
```

Check the type:

```python
rating = float(input("Enter your rating: "))

print(type(rating))
```

Output:

```text
<class 'float'>
```

## 6.5 Performing Calculations with Float Input

```python
price = float(input("Enter product price: "))
quantity = int(input("Enter quantity: "))

total = price * quantity

print("Total cost:", total)
```

Example interaction:

```text
Enter product price: 2500.50
Enter quantity: 4
Total cost: 10002.0
```

The program accepts a decimal price and a whole-number quantity.

## 6.6 Using `str()`

The `str()` function converts a value into a string.

Example:

```python
age = 18

age_text = str(age)

print(type(age_text))
```

Output:

```text
<class 'str'>
```

This is useful when you need to convert a number into text.

For example:

```python
age = 18

message = "I am " + str(age) + " years old."

print(message)
```

Output:

```text
I am 18 years old.
```

You can also use an f-string for this, which we will explore later.

## 6.7 Conversion Summary

| Function | Purpose | Example |
|---|---|---|
| `int()` | Converts to an integer | `int("25")` |
| `float()` | Converts to a float | `float("25.5")` |
| `str()` | Converts to a string | `str(25)` |

### Important Warning: Invalid Input

Consider:

```python
age = int(input("Enter your age: "))
```

If the user enters:

```text
Samuel
```

Python raises:

```text
ValueError
```

Why?

Because `"Samuel"` cannot be converted into an integer.

For now, understand that conversion functions expect compatible values.

You will learn how to handle invalid input more safely as your programming knowledge develops.

# 🎨 SECTION 8 — FORMATTING OUTPUT

Displaying information is important.

But displaying it clearly is just as important.

Compare these two outputs.

### Output A

```text
Samuel18Arsenal8.5
```

### Output B

```text
PLAYER PROFILE

Name: Samuel
Age: 18
Favourite Club: Arsenal

```

But Output B is much easier to read.

Let's explore how to improve your output.

## 8.1 Using Commas in `print()`

```python
name = "Samuel"
age = 18

print("Name:", name)
print("Age:", age)
```

Output:

```text
Name: Samuel
Age: 18
```

This is simple and beginner-friendly.

## 8.2 Using String Concatenation

You can join strings using `+`.

```python
name = "Samuel"

print("Welcome " + name)
```

Output:

```text
Welcome Samuel
```

However, you cannot directly concatenate a string and an integer.

Incorrect:

```python
age = 18

print("Age: " + age)
```

This produces a `TypeError`.

You would need to convert the integer:

```python
age = 18

print("Age: " + str(age))
```

Output:

```text
Age: 18
```

## 8.3 Using f-Strings

This is one of the most useful ways to format output in Python.

An f-string allows you to insert variables and expressions directly into a string.

You create an f-string by placing `f` before the opening quotation mark.

Example:

```python
name = "Samuel"
age = 18

print(f"My name is {name} and I am {age} years old.")
```

Output:

```text
My name is Samuel and I am 18 years old.
```

Notice:

```python
f"..."
```

The `f` tells Python to process the values inside curly braces.

For example:

```python
{name}
```

Is replaced with the value stored in `name`.

And:

```python
{age}
```

Is replaced with the value stored in `age`.

## 8.4 Using Expressions Inside f-Strings

You can perform calculations inside curly braces.

```python
goals = 12
assists = 8

print(f"Total contributions: {goals + assists}")
```

Output:

```text
Total contributions: 20
```

You can also display comparisons:

```python
age = 18

print(f"Eligible by age: {age >= 16}")
```

Output:

```text
Eligible by age: True
```

## 8.5 Formatting Decimal Places

Suppose a player has an average rating:

```python
rating = 8.56789
```

Displaying all decimal places may be unnecessary.

You can use:

```python
print(f"Rating: {rating:.2f}")
```

Output:

```text
Rating: 8.57
```

The `.2f` means:

Display the number as a floating-point value with two digits after the decimal point.

More examples:

```python
number = 15.6789

print(f"{number:.1f}")
print(f"{number:.2f}")
print(f"{number:.3f}")
```

Output:

```text
15.7
15.68
15.679
```

Python rounds the displayed value to the requested number of decimal places.

## 8.6 Formatting Numbers with Separators

Large numbers can be difficult to read.

Example:

```python
budget = 2500000

print(f"Budget: {budget:,}")
```

Output:

```text
Budget: 2,500,000
```

The comma format improves readability.

## 8.7 Creating a Simple Report

Let's combine these formatting techniques.

```python
name = "Samuel"
age = 18
goals = 12
assists = 8
rating = 8.56789

print("================================")
print("       PLAYER PROFILE")
print("================================")

print(f"Name: {name}")
print(f"Age: {age}")
print(f"Goals: {goals}")
print(f"Assists: {assists}")
print(f"Contributions: {goals + assists}")
print(f"Rating: {rating:.2f}")

print("================================")
```

Output:

```text
================================
       PLAYER PROFILE
================================
Name: Samuel
Age: 18
Goals: 12
Assists: 8
Contributions: 20
Rating: 8.57
================================
```

This is much more professional.

# ⚠️ SECTION 10 — COMMON INPUT / OUTPUT MISTAKES

Let's examine common mistakes.

## Mistake 1 — Forgetting That `input()` Returns a String

Incorrect:

```python
age = input("Enter age: ")

print(age + 5)
```

If the user enters `18`, Python raises a `TypeError`.

Why?

Because `age` is a string.

Correction:

```python
age = int(input("Enter age: "))

print(age + 5)
```

## Mistake 2 — Forgetting to Convert Decimal Input

Incorrect:

```python
rating = int(input("Enter rating: "))
```

If the user enters:

```text
8.5
```

Python raises a `ValueError`.

Correction:

```python
rating = float(input("Enter rating: "))
```

## Mistake 3 — Converting Text into an Integer

Incorrect:

```python
name = int(input("Enter name: "))
```

A name such as Samuel cannot be converted into an integer.

Correction:

```python
name = input("Enter name: ")
```

Use the appropriate data type for the information you expect.

## Mistake 4 — Forgetting Quotation Marks

Incorrect:

```python
print(Hello World)
```

Python treats `Hello` and `World` as names rather than text.

Correction:

```python
print("Hello World")
```

## Mistake 5 — Missing Parentheses

Incorrect:

```python
print "Hello"
```

In Python 3, `print` is a function.

Correction:

```python
print("Hello")
```

## Mistake 6 — Using `+` Between a String and Integer

Incorrect:

```python
age = 18

print("Age: " + age)
```

Correction:

```python
print("Age:", age)
```

Or:

```python
print(f"Age: {age}")
```

## Mistake 7 — Using the Wrong Conversion Function

Incorrect:

```python
price = int(input("Enter price: "))
```

If the price can contain decimals, use:

```python
price = float(input("Enter price: "))
```

## Mistake 8 — Forgetting to Store the Input

Consider:

```python
input("Enter your name: ")

print("Welcome!")
```

The program receives input, but it does not store it in a variable.

If you need to use the information later, assign it:

```python
name = input("Enter your name: ")

print(f"Welcome, {name}!")
```

## Mistake 9 — Confusing the Prompt with the Variable

In:

```python
age = input("Enter your age: ")
```

The variable is:

```python
age
```

The prompt is:

```text
Enter your age:
```

They serve different purposes.

## Mistake 10 — Assuming Every Input Is Valid

Consider:

```python
age = int(input("Enter age: "))
```

If someone enters:

```text
eighteen
```

The program fails with a `ValueError`.

For now, remember that `int()` and `float()` need compatible input.

Later, you will learn how to handle such errors using exception handling.
